# 📊 Khmer Loan Amortization Schedule Calculator

A web-based loan repayment and amortization schedule calculator built in Khmer for banking and lending workflows.

🔗 **Live Demo:** [https://rithratha.github.io/loan-calculator-demo/](https://rithratha.github.io/loan-calculator-demo/)

## ✨ Key Features
- **Loan Summary:** Calculates monthly installment, total interest, and total repayment amount.
- **Monthly Amortization Table:** Shows payment date, monthly payment, principal portion, interest portion, and remaining balance.
- **Khmer Interface:** Designed for clear readability in Cambodian lending operations.

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript
- GitHub Pages
